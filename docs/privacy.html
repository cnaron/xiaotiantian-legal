小天天练跳绳 · 隐私政策

版本 v2.0  ·  生效日期 2026-09-07  ·  更新日期 2026-09-07
取代 2026-05-12 的 v1.0

先说结论:

  • 本 App 没有任何联网上传功能。它不会把你的视频、跳绳记录或设备信息发送到任何服务器——因为它根本没有实现上传这件事。
  • 不收集姓名、生日、学校、班级、地理位置等任何个人身份信息;无需注册、无需登录,本 App 没有账号体系。
  • 未接入任何第三方分析、广告、登录、推送 SDK。
  • 跳绳视频只存在你自己的手机里,并且只保留最新的一局(详见第二节 2.3——这是本版相比上一版最重要的更正,上一版写的是"不保存视频",已不准确)。
  • Apple「健康」仅写入跳绳记录,从不读取你的健康数据。

「小天天练跳绳」(以下简称"本 App",App ID com.playtime.ropecounter)是一款面向中小学体测 / 中考跳绳训练的辅助应用。我们非常重视用户的隐私和个人信息保护,尤其是未成年人的信息保护。

一、我们不收集的信息

  • 姓名、生日、学校、班级、身份证号、学籍号
  • 手机号、邮箱、微信 / Apple ID 等账号(本 App 无账号体系)
  • 地理位置(GPS / IP 反查 / Wi-Fi)
  • 设备唯一标识 / IDFA / IDFV / 安装来源
  • 通讯录、浏览历史、搜索历史
  • 你「健康」App 里的任何数据(我们只写不读)

性别 / 年级 / 省份三项只作为本地体测评分参数使用,从不传出设备。

二、本 App 会用到的系统权限,以及各自用来干什么

下面 6 条与 App 内实际弹出的权限说明逐条对应。任何一条你都可以在 iOS「设置 → 隐私与安全性 → 对应项 → 小天天练跳绳」里随时撤回。

2.1 摄像头

用途:识别跳绳动作、完成计数,以及生成本次跳绳的回看视频。

画面由设备端模型实时处理,全程在你的手机本地完成,不经过任何服务器。识别用的关键点数据用完即丢;录下来的那条视频按 2.3 处理。

拒绝授权 ⇒ 自动计数无法使用。

2.2 麦克风

用途:把跳绳现场的声音录进你的回看视频里(绳子的声音、你的加油声)。

请注意:录制期间旁边的人说话也会被录进去。声音与视频一起,只存在你的手机本地,不会上传。

拒绝授权 ⇒ 视频照常生成,只是没有声音,不影响计数。

2.3 跳绳视频怎么存、存多久

  • 每完成一局,App 会在你的手机上生成一条本次跳绳的视频(画面上带跳数等信息),用于「回看上一局」。
  • 只保留最新的一局。下一局跳完,新的会自动覆盖旧的——手机里不会越攒越多。
  • 视频存在本 App 的沙盒目录里,其它 App 看不到;你可以主动把它保存到相册或通过系统分享面板分享出去,是否分享、分享给谁完全由你决定。
  • 绝不上传。本 App 没有实现任何上传通道,也没有接任何云服务。
  • 卸载 App = 视频连同全部本地数据一起删除。

2.4 Apple 健康(HealthKit)—— 可选

用途:在你授权后,把完成的跳绳训练以 Workout(跳绳)+ 估算卡路里写入系统「健康」App。

只写不读:我们从不读取你「健康」App 里的任何数据(体重、心率、睡眠等一概不读)。App 内声明的"健康读取"权限项仅为满足 Apple 的 HealthKit 权限框架要求而存在,没有任何代码去读。

2.5 相册(读 / 写)

  • 写入(保存):用于在你主动点击结果页的「保存到相册」时,把本次跳绳视频存进你的相册。
  • 读取(选片):用于让你从相册里挑一条已有视频,按与实时相机完全相同的流程重新数一遍;视频只在本机处理,不会上传。该入口在部分版本中可能不对外开放,权限声明保留以覆盖此用途。

两项都只在你主动操作时触发,App 不会自行翻看你的相册。

三、训练记录

每次跳绳测试会作为一条「记录」保存在你设备本地,包括:测试时间、模式、跳数、时长、平均速度、估算卡路里,以及体测模式下的省份 / 年级 / 性别与对应分数。

这些数据从不离开你的设备。你可以在 App 内逐条删除记录;卸载 App 时全部随之删除(除非你已主动同步到 Apple「健康」App——那份归「健康」App 管,可在其中单独删除)。

四、第三方 SDK:一个都没有

本 App 未接入任何第三方统计、广告、社交分享、推送、登录 SDK。仅使用 Apple 官方系统框架:

框架用途
AVFoundation / Vision / Core ML设备端摄像头处理与动作识别,纯本地运算
StoreKit 2处理 App 内购买。支付全程由 Apple ID 系统处理,我们不接触任何支付凭证、银行卡或付款信息
HealthKit在你授权后写入跳绳训练
Photos你主动点击时保存视频到相册 / 选片重放

六、未成年人保护

本应用主要面向中小学生及其家长。我们承诺:

  • 不要求提供任何个人身份信息,不要求注册账号,不收集设备唯一标识
  • 无社交、无排行榜、无好友 PK,避免攀比与沉迷
  • 无广告
  • 付费页明确提示建议在家长指导下购买,无限时倒计时、无焦虑式引导、无虚拟货币
  • 跳绳视频只存本机、只留最新一局、不上传(见 2.3)——这一条对未成年人尤其重要

我们遵守《中华人民共和国未成年人保护法》《未成年人个人信息网络保护规定》等法律法规。

给家长的话:本 App 不需要也不会索取孩子的任何身份信息;购买按你的 Apple ID 扣款,建议购买前与孩子沟通。

七、你的权利

  • 删除数据:App 内逐条删除记录;卸载 App 彻底清除全部本地数据(含回看视频)
  • 撤回授权:摄像头 / 麦克风 / 相册 / 健康授权,均可在 iOS 系统设置中随时撤回
  • 恢复购买:在 App 内「恢复购买」,凭 Apple ID 找回已购权益

由于我们不持有任何服务器端数据,不存在需要向我们申请"导出 / 更正"的信息。
