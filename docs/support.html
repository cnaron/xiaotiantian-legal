小天天练跳绳 · 支持与帮助

更新日期 2026-09-07  ·  联系邮箱 shengtang003@126.com

「小天天练跳绳」用 iPhone 摄像头帮孩子数跳绳次数,并对照公开的体测评分标准给出对应分数。所有识别都在手机本地完成,不联网、不上传。

常见问题

Q:数得不准怎么办?

A:把手机放在 1.5–2 米外、能拍到全身的位置,尽量让光线均匀、背景简单、衣物不要过于宽松。结果页可以对次数做微调,也可以直接填入你数到的真实次数。

Q:为什么没有我所在的省份?

A:目前收录了 6 套公开的官方评分标准:国家标准(教育部)、北京、上海、广东(广州)、江苏(南京)、浙江(杭州)。部分地区中考不考跳绳,或官方评分表未以可核验的形式公开,我们不会凭推测填入。后续会持续补充。

Q:视频存在哪里?会上传吗?

A:只存在你自己的手机里,而且只保留最新一局,下一局会自动覆盖。不会上传到任何服务器——App 里根本没有上传功能。卸载 App 即彻底删除。你也可以主动把它保存到相册或分享出去,是否分享完全由你决定。

Q:录像会录到声音吗?

A:会。授权麦克风后,绳子的声音、加油声,以及旁边的人说话都会被录进去。不想录可以在 iOS「设置 → 隐私与安全性 → 麦克风」里关闭本 App 的麦克风权限,视频照常生成,只是没有声音。

Q:买了会自动续费吗?怎么取消?

A:不会。到期不自动续费。本 App 卖的是买断 / 期限制:1 年 ¥28、3 年 ¥48 是非续期订阅(期限走完就回免费,Apple 不会自动扣款),永久 ¥128 是一次性买断。因此没有"取消订阅"这一步,你不需要做任何操作。已购 1 年 / 3 年的用户可以补差价升级为永久(1 年 → 永久 ¥98,3 年 → 永久 ¥78)。

Q:换手机 / 重装后功能没了怎么办?

A:用同一个 Apple ID 登录,在 App 内点「恢复购买」即可,系统会同步你的历史交易并按原始购买日重新算有效期。

Q:怎么退款?

A:退款由 Apple 处理,不由我们处理。iOS「设置 → 顶部你的 Apple ID → 订阅 / 购买记录 → 报告问题」,或访问 reportaproblem.apple.com。

Q:免费能用到什么程度?

A:自由跳、目标次数、目标时间等基础计数功能免费不限次;体测 / 中考模式免费累计可试用 3 次;历史记录免费可查看最近 3 条。购买后不限次数、完整历史与趋势图、可同步到 Apple「健康」。

Q:怎么删除我的数据?

A:历史记录可在 App 内逐条删除;卸载 App 会清除全部本地数据(含回看视频)。已同步到 Apple「健康」的记录请在「健康」App 内删除。

Q:需要注册账号吗?会收集我的信息吗?

A:不需要注册,本 App 没有账号体系,也没有接任何第三方统计 / 广告 SDK。姓名、学校、位置一概不收集。详见隐私政策。
