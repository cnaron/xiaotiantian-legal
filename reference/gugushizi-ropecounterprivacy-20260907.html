小天天练跳绳 隐私政策

版本更新日期：2026年5月12日

版本生效日期：2026年5月12日

引言

“小天天练跳绳”是一款由我们（以下简称“我们”）开发的中考体测跳绳训练辅助应用。我们非常重视用户的隐私和个人信息保护，尤其是未成年人的信息保护。

核心承诺：
  • 不收集姓名、生日、学校、班级、地理位置等任何个人身份信息
  • 无需注册账号，无需登录
  • 未接入任何第三方分析、广告、登录、推送 SDK
  • 摄像头视频帧仅用于本地跳绳动作识别，识别后立即丢弃，绝不保存或上传
  • Apple 健康仅写入跳绳记录，从不读取你的健康数据

请在使用我们的产品前，仔细阅读并了解本政策。

一、 我们收集的信息

1. 个人信息

我们 不收集 用户的任何个人身份信息，包括但不限于：姓名、手机号、邮箱、身份证号、生日、学校、班级、家庭住址、精确或粗略地理位置、设备唯一标识符（IDFA / IDFV）、IP 地址等。您无需注册或登录即可使用本应用的全部功能。

2. 应用内本地数据

以下数据 仅存储在您的设备本地，由 iOS 沙盒保护，不会上传到任何服务器：

  • 跳绳记录：每次测量的跳绳次数、时长、速度、估算卡路里、中考评分（如开启了中考标准模式）
  • 偏好设置：所选省份、年级、性别（仅用于匹配中考体测标准评分表，不与你的真实身份关联）
  • 引导状态：是否已完成首次引导

这些数据在你卸载本应用时会随沙盒一同清除，我们没有任何途径访问。

3. 设备权限调用

为了实现产品的核心训练功能，我们可能会在您使用过程中向您申请以下系统权限：

  • 摄像头权限

    用途：用于本地识别跳绳动作（计数）。

    说明：视频帧由设备端模型实时处理，处理完成后立即从内存中释放。我们不保存任何视频、图片或截图，也不会上传到任何服务器或第三方机构。

    如果您拒绝授予摄像头权限，您将无法使用自动计数功能，但仍可手动记录跳绳次数。

  • Apple 健康（HealthKit）权限 — Pro 会员功能

    用途：将完成的跳绳训练以 Workout（跳绳） + 估算卡路里写入系统「健康」app，便于你在「健康」app 内整合查看运动数据。

    说明：我们仅请求 写入 权限，从不读取你的任何健康数据（如步数、心率、体重等）。HealthKit 的读取权限声明仅为满足 Apple 平台技术要求而存在，代码中未调用任何读取接口。

    如果您拒绝授予 HealthKit 权限，您将无法将训练记录同步到「健康」app，但这不影响本应用其他功能。

二、 第三方 SDK 集成情况

为了最大限度保护用户隐私，“小天天练跳绳”未接入任何第三方分析、广告、登录、推送、统计、定位、社交分享类 SDK。这意味着您的设备信息和使用习惯不会被任何第三方机构获取。

本应用仅使用以下系统级框架，均为 Apple 官方提供：

  • StoreKit 2：用于处理订阅购买（Pro 会员）。支付由 Apple ID 系统全程处理，我们不接触任何支付凭证、银行卡或个人付款信息。
  • HealthKit：用于（在用户授权后）将跳绳训练写入「健康」app。
  • AVFoundation / Vision：用于设备端摄像头处理与动作识别，纯本地运算。

三、 信息的存储与保护

  1. 存储地点：所有跳绳记录与偏好设置均仅保存在您的设备本地（iOS 沙盒），不涉及任何服务器上传。
  2. 存储期限：由您本人控制。您可在设置中清空记录，或卸载本应用以彻底删除全部数据。
  3. 安全措施：本应用采用 iOS 沙盒机制，应用之间相互隔离。我们承诺将严格遵守相关法律法规，采取符合行业标准的安全防护措施。

四、 订阅与支付

本应用提供 Pro 会员订阅服务（月订阅 / 年订阅），用于解锁中考评分、趋势图、Apple 健康同步等高级功能。

  • 支付由 Apple ID 系统全程处理，我们不接触您的任何支付凭证、银行卡或个人付款信息。
  • 订阅状态由 StoreKit 2 实时校验，仅在本设备本地缓存订阅有效期标识，不上传到任何服务器。
  • 订阅自动续费由 Apple ID 系统处理，您可随时在 设置 → Apple ID → 订阅 中取消。
  • 详细订阅条款见 用户协议。

五、 未成年人保护

本应用主要面向中小学生（约 10–15 岁），属于未成年人较多的使用群体。我们承诺：

  • 不要求未成年人提供任何个人身份信息
  • 不要求注册账号、不收集设备唯一标识
  • 无社交、排行榜、好友 PK 等可能引发攀比与沉迷的功能
  • 付费页明确建议"由家长或监护人指导后开通订阅"
  • 严格遵守《未成年人保护法》《未成年人个人信息网络保护规定》

如果家长发现我们在不知情的情况下收集了未成年人的个人信息（理论上不会发生，因为我们不收集），请通过本政策下方的联系方式联系我们，我们会立即核查。

六、 您的权利

由于我们不收集任何个人信息，没有需要您"删除""更正""导出"的服务器端数据。但您依然享有以下控制权：

  • 清除本地数据：在「设置 → 开发选项 → 清空所有记录」即可清空本地跳绳记录（仅 Debug 版本可见；正式版需卸载应用）。
  • 撤回权限：在 iOS「设置 → 隐私 → 摄像头 / 健康 → 小天天练跳绳」可随时关闭权限授予。
  • 取消订阅：在「设置 → Apple ID → 订阅」可随时取消自动续费。
  • 彻底删除：卸载本应用即可彻底删除所有本地数据。

七、 本政策的修订

我们可能会适时修改本隐私政策的条款。如果涉及重大变更（如接入新的权限或开始收集新的信息），我们会在应用内通过显著方式提醒您，并在本页顶部更新"版本更新日期"。重大变更生效前，您可以选择停止使用本应用。
